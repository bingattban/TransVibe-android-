# Phase 01 — خطوات استكمال اختبار البناء على Code On The Go

هذه تعليمات تحقق، وليست إثباتا أن APK قد بني أو اشتغل. **لا تحذف** النسخة الإنتاجية المثبتة أو بياناتها بسبب تعارض التوقيع.

## 1. التحضير

- فك ضغط مشروع TransVibe كاملا بحيث يظهر مجلد `TransVibe` وجذره `settings.gradle.kts`.
- تأكد من أن Code On The Go لديه اتصال مؤقت بالإنترنت عند تنزيل Gradle والاعتمادات لأول مرة، وأن JDK 17+ وAndroid SDK 35 وNDK/CMake المطلوبة متوفرة. لا تفترض نجاح تثبيت أي منها قبل مشاهدة سجل حقيقي.
- إذا توفر طرفية أو shell، ادخل إلى مجلد `TransVibe` ونفذ:

```sh
sh phase01/validate_on_code_on_the_go.sh
```

- النتائج والسجلات في `phase01/cotg_device_logs/`، وأهمها `PHASE01_BUILD_RESULTS.txt` وسجلات كل Gradle task.
- إذا لم يدعم Code On The Go الطرفية، نفذ هذه المهام من واجهته بالترتيب نفسه وسجل مخرجاتها حرفيا:

```text
:app:clean
:app:testDebugUnitTest
:app:assembleDebug
:app:assemblePreview
```

## 2. ملفات APK المتوقعة

- Debug: `app/build/outputs/apk/debug/app-debug.apk`؛ معرفه `com.transvibe.app` وقد يتعارض توقيعه مع الإنتاجي. **لا تثبته محل الإصدار الحالي**.
- Preview: `app/build/outputs/apk/preview/app-preview.apk`؛ معرفه `com.transvibe.app.preview` ويمكن اختباره بجانب الإنتاجي دون مشاركة مجلد بيانات التطبيق الخاص.
- لا تنقل هذه الملفات إلى هاتف آخر قبل توثيق الاختبارات إذا كان الملف الناتج يختلف عن المتوقع.

## 3. اختبار الجهاز الضروري، خارج مرحلة البناء الآلي

1. تثبيت **Preview فقط** من مدير الملفات على هاتف ARM64، بعد سماح Android بالتثبيت من المصدر المستخدم.
2. التشغيل الفعلي للتطبيق والوصول إلى الشاشة الرئيسية والإعدادات، وتسجيل أي خطأ أو إغلاق مفاجئ.
3. توثيق نوع الهاتف وإصدار Android والمعمارية، والتحقق من معرف حزمة Preview والتوقيع ونوع البناء إن أمكن.
4. إرفاق سجل البناء الكامل وسجل الانهيار عند وقوعه. إزالة بيانات خاصة/مفاتيح/مسارات شخصية قبل مشاركة السجلات.

## 4. حدود النجاح

- نجاح `assembleDebug` و`assemblePreview` و`testDebugUnitTest` لا يثبت عمل التعرف الصوتي؛ الجسر التشخيصي ليس Whisper أو Sherpa حقيقيين.
- Release محجوب عمدا عند غياب `third_party/whisper.cpp` وحزمة Sherpa-ONNX الفعلية. لا تتجاوز هذا الحاجز.
- لا تعد المرحلة 01 **PASSED** حتى تكتمل اختبارات البناء والتثبيت والتشغيل الحقيقي على ARM64 وتُراجع سجلاتها.
