# TransVibe (`com.transvibe.app`)

Offline-first Android video transcription and Arabic subtitling application built with Kotlin, Jetpack Compose (Material 3 RTL), Room, MediaCodec, Media3 ExoPlayer, ML Kit on-device Translation, whisper.cpp JNI, and Sherpa-ONNX adapters.

See `CODE_ON_THE_GO_BUILD.md` and `PHASE_REPORT.md` for build instructions and honest gate status.
